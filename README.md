# Proyecto: De patria a patria 🌍

Este es un proyecto de práctica de diseño web enfocado en la creación de una página de aterrizaje (landing page) visualmente atractiva, informativa y, sobre todo, **completamente responsiva**. El objetivo es mostrar las historias y orígenes de diversos profesionales alrededor del mundo.

## 🚀 Tecnologías Utilizadas

- **HTML5:** Estructura semántica para mejorar la accesibilidad y el SEO.
- **CSS3:** Estilizado avanzado utilizando metodologías modernas.
- **Metodología BEM (Block Element Modifier):** Para mantener un código CSS organizado, escalable y fácil de leer.
- **Flexbox:** Para la alineación y distribución eficiente de los elementos.
- **Media Queries:** Implementación de diseño adaptativo para Desktop, Tablet y Móvil.

## 🛠️ Características del Proyecto

- **Diseño Adaptativo:** La interfaz se ajusta dinámicamente a resoluciones de:
  - 💻 Desktop (1280px+)
  - 📱 Tablet (768px)
  - 📲 Móvil (544px y menores)
- **Optimización de Imágenes:** Uso de gráficos vectoriales (SVG) para mantener la calidad en cualquier densidad de pantalla.
- **Tipografía:** Uso de la familia tipográfica "Inter" para una lectura clara y moderna.
